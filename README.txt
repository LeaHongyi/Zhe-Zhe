微博图文归档使用说明

1. 双击 index.html 即可在浏览器中离线查看。
2. 分享时请发送整个文件夹，或发送同目录下的 ZIP 压缩包。
3. 点击图片可放大，点击“下载原图”可保存单张图片。
4. 可在 POSTS 与 ALBUM 两种视图之间切换浏览。
5. 如需公开网址，可将整个文件夹上传到任意静态网站托管服务。
新笔记（站内直接发布）
1. 点击首页右上角或笔记页底部的 ＋，选择相册、相机或写文字。
2. 照片可预览、移除、添加或设为封面，再点击下一步填写标题和正文。每篇最多9张；图片转为最长边1920px的JPEG后上传。
3. 首次点击“连接账号”，按弹窗说明用 LeaHongyi 创建仅授权本仓库 Contents 读写的 fine-grained 发布凭证并连接。不要把凭证发给别人。
4. 默认仅当前会话保留连接；主动勾选“在这台设备上保持连接”才会保存在本机浏览器。凭证仅发送至 api.github.com，断开连接会清除本机保存的凭证，到期需重新连接。
5. 发布笔记会将照片和文字在同一条提交中保存至仓库，确认成功后才显示成功。其他访客可在笔记页刷新读取。GitHub Pages 自动发布可能稍有延迟。
6. 草稿含压缩照片，通过 IndexedDB 保存在当前设备，可在 ＋ 菜单继续编辑，不会跨设备同步。发布成功后清除当前草稿。
7. 新笔记位于 notes-data.json，照片位于 notes-images/，原始归档及 images/ 不受影响。发布失败保留草稿，不强制覆盖远端分支。
