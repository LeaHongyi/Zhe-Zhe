微博图文归档使用说明

1. 双击 index.html 即可在浏览器中离线查看。
2. 分享时请发送整个文件夹，或发送同目录下的 ZIP 压缩包。
3. 点击图片可放大，点击“下载原图”可保存单张图片。
4. 可在 POSTS 与 ALBUM 两种视图之间切换浏览。
5. 如需公开网址，可将整个文件夹上传到任意静态网站托管服务。
新笔记（公开同步）
1. 网站右上角点击“新笔记 / 发布 ＋”，再点击“写笔记”。
2. 填写标题和正文；草稿自动保存在当前浏览器，可预览。
3. 点击“前往 GitHub 发布”，用 LeaHongyi 账号登录。在 GitHub 正文框可拖入图片，等待上传完成后点击 Create / Submit new issue。
4. 保留标题开头的 [笔记] 和后面的空格。发布后返回笔记页点击“刷新笔记”，所有访客都能读取。
5. 点击笔记下方“查看原文 / 编辑”可修改；关闭该 Issue 可从网站下架，重新打开后恢复。
6. 网站仅显示 LeaHongyi 创建的、标题以 [笔记] 开头且状态为 open 的 Issue。访客提交的内容不会显示。
7. 笔记通过 GitHub 公共 API 读取；网络不可用或触发访问频率限制时，请稍后刷新。草稿不会自动上传，网站不保存 GitHub 密码或令牌。
